# v1.1 Head Results

Saved aggregates from the frozen seed-43 shared-head run and its separate
quality and serving panels. One FP32 head scores text and images from frozen
Qwen3.8-Flash-Next features. No held-out result selects the training arm or
extends its budget. The [recipe](train-v1.1-head.md) records the successful
matched training and separate text CAL.

Decision results below were measured on the v1.1 release candidate before the
[decision-root scheduling fix](integration-v1.1.md#decision-root-checks);
prefill and decode do not use that path.

## Provenance And Limits

The matched text run uses archive unpublished lab commit ID `d7d7ee4`
and runtime unpublished lab commit ID `1fc9054`. The source inventory
records native capture at engine unpublished lab commit ID `1c2985f0`,
plugin unpublished lab commit ID `b422d0d` and runtime unpublished lab commit
ID `1fc9054`; it does not identify every historical cached row's producer.
The curated aggregates omit private paths, per-item IDs and request and
response text.

- The SugarCrepe sample excludes 84 earlier COCO images, including IDs from A-OKVQA metadata; overlap checks use COCO image IDs only.
- Image Choice is validated at K2 only; image Noul/Ordinal and larger image slates remain unvalidated.
- Text Ordinal quality is unvalidated; Ordinal255 keeps raw probabilities beyond CAL K5.
- WANDS K views are dependent; sparse CAL and worse high-K ECE remain explicit.
- Cached Kev retention and text Noul K2 results are conditional on the FP16-KV, batch-8 feature cache; the frozen-v1 current-engine panels use the served engine.
- [Served v1.1 quality](v1.0-v1.1-comparison.md) covers text and experimental images. New-head seed variance is unmeasured.
- The paired API panel measures capacity and retained-path behavior.
